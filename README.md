# 001 — Grok 질문 전용

이 저장소는 앱을 만드는 곳이 아닙니다. **질문(Ask)만** 하는 Grok 워크스페이스입니다.

## 쓰는 방법

Cursor Cloud Agent에 질문만 보내면 됩니다.

- 설명, 아이디어, 번역, 초안, 비교, 학습 질문 → 여기서
- 코드 구현, 버그 수정, 서버 실행, PR 작업 → 다른 저장소에서

## 에이전트 동작

이 저장소의 에이전트는 기본적으로 아래만 합니다.

- 한국어로 질문에 답한다
- 저장소 파일을 만들거나 바꾸지 않는다
- 브랜치, 커밋, 푸시, PR을 만들지 않는다
- 서버(`uvicorn` 포함)를 실행하지 않는다

규칙은 `AGENTS.md`와 `.cursor/rules/ask-only.mdc`에 있습니다.

설정을 바꾸고 싶을 때만 “ask-only 설정을 수정해라”고 분명히 말하면 됩니다.
